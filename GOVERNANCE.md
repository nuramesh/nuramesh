# How the NuraMesh project is run

NuraMesh is an open-core project. This repository is the open core, licensed under the Apache License
2.0. This page says who decides what, so you know what to expect before you invest time.

## Who maintains it

NuraMesh is developed and maintained by AI Collective Labs Inc. The maintainers are the people at the
company who work on NuraMesh. They set the roadmap, review and merge changes, and publish releases.

## How decisions are made

- The maintainers decide what goes into the project. They discuss changes that affect users in issues
  of this repository, so the reasons are public.
- Anyone may propose a change. Open an issue first, as `CONTRIBUTING.md` describes. The maintainers
  review pull requests when they can and may decline a change that does not fit the project's scope.
- Some rules are not open to trade-offs, because the project's purpose depends on them: a task is done
  only when its gates pass, verifiers stay independent of the worker, budgets are hard stops, the ledger
  is append-only, autonomy is default deny, and the open core sends no telemetry and never checks a
  licence over the network.

## Releases and compatibility

NuraMesh is pre-1.0, so interfaces may change between releases. `CHANGELOG.md` records what changed in
each release. Versions follow Semantic Versioning once 1.0.0 is published.

## Licence and contributions

The open core is licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`). Contributions are accepted
under the same licence, as `CONTRIBUTING.md` says. The name and logo are covered by `TRADEMARKS.md`.

## Security and conduct

Security reports follow `SECURITY.md`. Everyone taking part follows `CODE_OF_CONDUCT.md`; the
maintainers enforce it.

## Changes to this page

The maintainers may change how the project is run. Changes to this page go through the same public
review as any other change.
